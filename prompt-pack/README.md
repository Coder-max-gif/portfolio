# Anuvamshi Shetty – Portfolio Website Prompt Pack

Founder, Lighthouse Capital (boutique investment bank).
Brand idea: "Ambition deserves access." + the lighthouse metaphor (one beam of light finding the right people).

## How to use
1. Open `01_MASTER_PROMPT.md` and paste it into Claude / Cursor / v0 / Lovable. This is the main prompt.
2. When the tool asks for details, or in a second message, paste the other files:
   - `02_DESIGN_SYSTEM.md`  -> colors, type, glass rules
   - `03_MOTION_SPEC.md`   -> every animation, with timings
   - `04_COPY_DECK.md`     -> her real words, section by section
   - `05_VIDEO_SHOOT_BRIEF.md` -> cinematic hero video (give to videographer)
   - `06_ANTI_AI_CHECKLIST.md` -> final review so it does not look AI-made
3. Replace every [PLACEHOLDER] with real facts (numbers, deals, logos, photos). Never invent numbers or deals.

## Build order
Hero -> Story scroll -> Principles -> Services -> Beliefs -> Contact -> polish motion -> mobile -> performance.
